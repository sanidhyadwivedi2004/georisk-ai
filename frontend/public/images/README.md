# Media Assets Directory

Place production-ready static assets in this directory according to the specifications in [ASSETS.md](../ASSETS.md).

### Directory Structure:
- `geopolitical/` — Satellite views of maritime chokepoints and conflict corridors
- `infrastructure/` — Terminals, refineries, pipelines, and storage hubs
- `events/` — Event-specific intelligence media and radar telemetry

All components in GeoRisk AI gracefully degrade with high-fidelity CSS and vector SVG fallbacks when static assets are not populated.
